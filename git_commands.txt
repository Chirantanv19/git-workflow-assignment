Git Commands Documentation
==========================

1. mkdir git-workflow-assignment && cd git-workflow-assignment
   Creates the local project folder and navigates into it.

2. git init -b main
   Initializes a new local Git repository and sets the default branch name to main.

3. git status
   Displays the working directory state, showing untracked, modified, or staged files.

4. git add <file>
   Stages specified file changes so they are ready to be recorded in the next commit.

5. git commit -m "<message>"
   Saves a permanent snapshot of staged changes to the repository history with a descriptive message.

6. git branch feature
   Creates a new parallel branch named 'feature' pointing to the current commit.

7. git checkout <branch-name>
   Switches the active working directory to the specified branch (used to move between 'feature' and 'main').

8. git merge feature --no-ff -m "<message>"
   Integrates changes from the 'feature' branch into 'main' while creating an explicit merge commit to preserve branch history.

9. git log --graph --oneline --all
   Displays a compact visual ASCII graph of the entire commit and branching history across all branches.

10. git revert HEAD --no-edit
    Undoes the changes introduced by the most recent commit by creating a new inverse commit, preserving full audit history.

11. git remote add origin <repository-url>
    Links the local Git repository to the remote public repository hosted on GitHub under the alias 'origin'.

12. git push -u origin --all
    Uploads all local branches and their complete commit histories to the remote GitHub repository.
